vpost

A private publishing tool for my own YouTube channels. Developed with YouTube API Services.

What it does

vpost is a small command-line tool I wrote to publish my own finished videos to my own YouTube channels with every upload setting filled in correctly each time:

  • Title, description, tags, category and language
  • "Altered or synthetic content" disclosure and made-for-kids setting
  • Captions (.srt), playlist and a scheduled publish time
  • Reading my own channels' statistics and YouTube Analytics to see how each video performs

Every command is a dry run by default and shows exactly what will change. Nothing is uploaded until I confirm.

Who can use it

Only me, on channels I own and have signed in to with Google OAuth. vpost is not offered, sold or distributed to anyone else. It never accesses other people's channels, and it never downloads or re-hosts YouTube content.
