Privacy Policy

Last updated: November 18, 2026

vpost is a personal tool used only by its author to manage the author's own YouTube channels. This policy explains what data it handles.

YouTube API Services

vpost uses YouTube API Services (the YouTube Data API and YouTube Analytics API). By using vpost you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data vpost accesses

  • Google OAuth tokens for the signed-in channel owner, so vpost can upload and manage videos on that owner's channels.
  • Channel and video details for the owner's own channels: video IDs, titles, privacy status, publish times, playlists and statistics (views, likes and similar).
  • YouTube Analytics reports for the owner's own channels: views, watch time and audience retention.

vpost does not access any other user's account, channel or personal information.

How the data is used

Only to upload the owner's videos with the chosen settings, confirm that uploads worked, and show the owner how the videos are performing.

Storage

OAuth tokens are stored only on the owner's own computer and never leave it except in requests to Google. Statistics are shown in the terminal. The owner may copy summary figures about the owner's own channels into private notes on the same computer. API data is refreshed from YouTube whenever it is used again. vpost does not run servers or databases and does not keep data anywhere else.

Sharing

vpost does not sell, share or send any data to third parties. Data goes only between the owner's computer and Google.

Cookies and tracking

vpost does not use cookies, analytics or tracking of any kind. This website does not set cookies.

Revoking access and deleting data

You can revoke vpost's access to a Google account at any time through the Google security settings page. Revoking access makes the stored token useless. Deleting the token files on the owner's computer removes them completely. Any locally stored API data is deleted on request, within 7 days at the latest.

Contact

Questions or data requests: open an issue at github.com/harper2045-ops/vpost-site/issues.
